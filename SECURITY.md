# Segurança

## Achou uma falha de segurança?

**Não abra uma issue pública** — ela fica visível para qualquer pessoa antes de
a falha ser corrigida.

Use o relato privado do GitHub: aba **Security** deste repositório →
**Report a vulnerability**. Só os mantenedores veem o relato.

Conte, se puder:

- o que encontrou e onde (endereço, tela ou arquivo);
- como reproduzir, passo a passo;
- o que alguém conseguiria fazer com isso.

Respondemos em até 5 dias úteis, e avisamos quando a correção estiver no ar.
Por favor, não acesse nem altere dados de clientes além do mínimo para
demonstrar o problema.

## O que está coberto

A versão em produção (o ramo que vai para o servidor) e a versão mais recente
do app nas lojas.
